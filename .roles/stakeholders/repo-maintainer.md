# Repo Maintainer

## Primary concerns

- Status reports identify broken links, duplicate anchors, stale outputs, and orphan pages.
- Strict mode catches issues worth blocking merges.
- Markdown reports can be committed or pasted into issue threads.
- Named views let maintainers track the same slice over time.
