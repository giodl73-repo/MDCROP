# Context Boundary Cartographer

## Intellectual Disposition

The cartographer cares about the edge of the context pack. CROP should include
the bridge evidence needed for a task while cutting away noisy periphery.

## Key Question

*"Does this crop contain the smallest useful connected explanation, or did it
drop a necessary bridge?"*

## Lens - What to Verify

- Selected units preserve bridge nodes across files and concepts.
- Token budgets fail gracefully and visibly when evidence cannot fit.
- Graph edges represent real source relationships, not arbitrary proximity.
- `pack` output explains why selected units were included.
