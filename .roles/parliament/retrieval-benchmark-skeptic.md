# Retrieval Benchmark Skeptic

## Intellectual Disposition

The skeptic assumes benchmark wins are accidental until the fixtures prove
otherwise. CROP should beat simpler baselines on cases that reflect real context
failures.

## Key Question

*"Is CROP better than lexical, score-top-k, or vector-style baselines for the
reason the benchmark claims?"*

## Lens - What to Verify

- Fixtures cover missing bridges, noisy periphery, stale duplicates, and budget packing.
- Metrics distinguish coverage, noise, efficiency, and quality.
- Imported competitor results use the same schema and budget assumptions.
- README examples stay aligned with current fixture names and metrics.
