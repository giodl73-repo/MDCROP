# CROP - Role Index

Roles for reviewing CROP as a graph-cut context, corpus-health, and
evidence-pack tool. Read this before opening any role file.

---

## Parliament roles

Adversarial product and infrastructure voices for CROP design reviews.

| File | Voice | Primary tension |
|---|---|---|
| `parliament/context-boundary-cartographer.md` | Context Boundary Cartographer | Small focused packs vs. missing bridge evidence |
| `parliament/corpus-health-auditor.md` | Corpus Health Auditor | Helpful status reports vs. noisy repository lint |
| `parliament/retrieval-benchmark-skeptic.md` | Retrieval Benchmark Skeptic | Real retrieval gains vs. fixture overfitting |
| `parliament/provenance-linkage-auditor.md` | Provenance Linkage Auditor | Traceable source units vs. anonymous snippets |
| `parliament/view-contract-keeper.md` | View Contract Keeper | Reusable named views vs. ad hoc CLI flags |
| `parliament/performance-budget-engineer.md` | Performance Budget Engineer | Fast local packing vs. expensive exhaustive analysis |

---

## Editorial roles

Quality gates before a CROP change is considered ready.

| File | Role | Checks |
|---|---|---|
| `editorial/readme-surface-editor.md` | README Surface Editor | README examples match current CLI and public story |
| `editorial/cli-contract-editor.md` | CLI Contract Editor | Subcommands emit stable schemas and clear errors |
| `editorial/fixture-documentation-editor.md` | Fixture Documentation Editor | Fixtures explain what they prove and how to rerun them |

---

## Stakeholder roles

Consumer lenses for deciding whether CROP serves real downstream uses.

| File | Stakeholder | Primary concern |
|---|---|---|
| `stakeholders/rag-builder.md` | RAG Builder | Focused context packs improve retrieval before LLM calls |
| `stakeholders/repo-maintainer.md` | Repo Maintainer | Status, links, headings, and frontmatter checks are actionable |
| `stakeholders/proof-publisher.md` | PROOF Publisher | Generated docs and artifact inventories stay publishable |
| `stakeholders/future-agent.md` | Future Agent | Named views and reports make handoff/resume work easy |
