# mdcrop-scout

Use before major MDCROP design or product changes.

## Checklist

1. Identify the buyer-visible win: noise reduction, missing bridge recovery,
   provenance, freshness, latency, or token-budget improvement.
2. Compare against ordinary top-k vector retrieval and current RAG frameworks.
3. State which graph technique earns the win: graph cuts, community detection,
   centrality, path search, typed edges, or budgeted packing.
4. Convert the finding into a fixture that can be tested without an LLM.
