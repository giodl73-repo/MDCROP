# Producer review and fixture acceptance

These checks are applied by the implementing agent. They are not independent
review, human approval, consumer acceptance or evidence of a deployed product.

| Lens | Finding and boundary |
|---|---|
| Context Boundary Cartographer | Accept the four-node fixture for explaining selected/excluded evidence. Show bridge reasons and seed-budget overruns. A selected pack does not prove semantic closure, whole-corpus coverage, counterexample absence or answer authority. |
| Retrieval Benchmark Skeptic | Retain existing synthetic score-top-k comparison only as fixture motivation. Current Qdrant/LlamaIndex docs inform the scope comparison, not a benchmark. No real-corpus, competitor-superiority, latency or customer-readiness claim. |
| Provenance Linkage Auditor | Retain exact source IDs, text and prefixed SHA-256 values. Independently recompute all four fixture hashes. Downloaded fixture provenance identifies synthetic repository content, not external-source authentication. |
| Performance Budget Engineer | Accept fixed four units, integer budgets 1–256 and bounded controls as a prototype envelope. The native seed can exceed the budget. Compile/link proof is not startup/compute timing, browser responsiveness or a heap quota. |

| Fixture Documentation Editor | Native snapshot retains twenty representative responses; four probe tests cover 1,024 admitted pairs, provenance, bridge selection, overrun, invalid controls and retained snapshot drift.
